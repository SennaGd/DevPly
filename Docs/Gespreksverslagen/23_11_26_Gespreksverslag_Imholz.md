Aanwezig: Sven Imholz ( Productowner )

Dit gesprek vond plaats om de voortgang van het project Development- en releaseplatform te raadplegen hierdoor komt de productowner te weten wat er gemaakt is en wat er gemaakt zal worden in de komende weken.

Tijdens het gesprek vertelde ik aan Imholz dat ik tijdens dit gesprek alleen de voortgang ging tonen. Als eerst vertelde ik aan Imholz dat ik een script gemaakt had dat een database kan opzetten, natuurlijk had Imholz geen idee wat het inhield. Ik vertelde dat hij zich geen zorgen hoefte te maken over deze script sinds ik dit later eenvoudig zal maken voor hem. 

Daarna vertelde ik dat ik een API endpoint had aangemaakt dat ervoor zorgt dat data vanaf de api naar de website komt. Met deze endpoints vertelde ik dat ik een login functie aangemaakt had dat op de website gebruikt kan worden ook dat er een registreer functie is om een account aan te maken. 

Wanneer een gebruiker ingelogd is zal deze gebruiker kunnen zien wat voor projecten hij heeft aangemaakt. Daarnaast liet ik ook zien dat je naar de projectpagina kon gaan alleen was deze pagina helemaal leeg dus dit zei Imholz niet zo veel, ik liet hem wel weten dat ik hier de komende week mee bezig zou gaan om alle requirements, ontwikkeltaken en tests  daaraan toe te voegen. 

Als afsluiting vertelde ik Imholz dat ik als eerst alle functionaliteiten zal implementeren sinds het beter is om een werkende applicatie te hebben zonder ontwerp dan een applicatie met een mooi ontwerp en niet werkende functionaliteiten. Imholz vertelde mij dat hij mij daarop vertrouwde en dat hij het goed vondt.
